# Poder do Parto — Funil

Repositório único das landing pages do funil O Poder do Parto.

## Rotas

- `/aula` — aula gratuita e oferta revelada após o vídeo
- `/aula-offer` — oferta apresentada após a aula
- `/oferta` — landing page principal da oferta
- `/guia` — landing page do Guia das 18 Perguntas
- `/guia/obrigado` — confirmação do Guia

A rota raiz `/` redireciona para `/aula`.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O projeto usa Vite, TanStack Start, React e Tailwind CSS.
